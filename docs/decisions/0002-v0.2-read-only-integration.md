# Decision 0002: authorize the v0.2 read-only integration prerelease

- Status: approved
- Date: 2026-08-27
- Decision owner: LockedIn Labs release owner

## Decision

Authorize a `v0.2.0` GitHub prerelease of SprintLoop Assurance Kit after the publication gates below pass. The release adds a local read-only MCP server, hardened exact-candidate Git observation, a manual/scheduled no-secret shadow provider, and the shared canonical release-subject contract.

The MCP surface is advisory and offline. The shadow provider emits a partial manifest and can conclude only `HOLD`; it cannot sign, authorize, publish, modify an SCM check, or become a required gate. A complete `PASS` still requires an authenticated out-of-band provider, independently governed verifier receipt, named finite authorization, and current receiver context.

## Immutable revisions

- Reviewed Action/runtime revision: `7dfb1e417256f08a7b5e149093cc4d4c5987ea5e`
- Reviewed source and pin revision: `35febce58e85ceec126ee6ce940461a25cfbe93e`
- Release/tag source revision: a clean descendant of the reviewed source/pin revision containing only immutable Action pinning, release records, and copyable source-pin documentation; its package release record must name the exact tag source.

Every copyable and remote-smoke Action reference must remain pinned to the reviewed Action/runtime revision. The prerelease tag must target the clean release source, not the Action/runtime revision. Any evaluator, cryptography, Git observer, MCP, materializer, shadow-provider, schema, or Action behavior change voids this approval and requires a new reviewed runtime revision.

## Required publication gates

1. Clean `npm run release:dry-run` passes and produces exactly the v0.2 tarball, SPDX SBOM, package release record, release notes, and `SHA256SUMS` for the tag source.
2. Local verify, fixture, sensitive-data, installed-package, MCP stdio, Git-hostility, materializer, and shadow-provider gates pass.
3. Hosted `verify`, `golden-path`, remote immutable Action smoke for all three Action entry points, and release-candidate dry-run pass.
4. The eight executable Action references and shadow-provider guide resolve to the reviewed Action/runtime revision.
5. The canonical schemas are served at their advertised HTTPS identifiers with a JSON Schema media type and exact source bytes.
6. Private vulnerability reporting and repository security/branch settings from Decision 0001 remain enabled and verified.

No npm publication, Marketplace listing, hosted enforcement authority, required-check promotion, production service claim, private SprintLoop code, customer data, credential, or signing key is authorized by this decision.
